Как пользоваться (1 минута)

  1. Нажми Connections → добавь API Key + Secret биржи → Connect.
  2. Вернись сюда. Светофор справа: зелёный Trading = можно торговать.
  3. Market (стакан/лента) работает и без ключей — публичные данные.
  4. Кликни окно стакана (станет активным). Выбери объём 0.01 / 0.05 / …
  5. BUY / SELL = market. Клик по цене в стакане = limit. Esc = снять ордера. X = закрыть позицию.
